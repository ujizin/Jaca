# Companion gRPC contract

`companion.proto` (package `jaca`) is the protocol between Jaca on the Mac and the [companion app](../mobile/README.md) on an Android phone. The link uses TLS.

| Side | Role | Generated code |
|---|---|---|
| Companion app (phone) | gRPC **server** | Java lite stubs, generated by the Gradle build of `mobile/companion-grpc` (`java_package` `dev.srsouza.jaca.grpc`) |
| Jaca (Mac) | gRPC **client** | Swift stubs in `Sources/Core/Companion/Generated/` (`companion.pb.swift`, `companion.grpc.swift`), checked in |

## Service `Companion`

| RPC | Data goes | Purpose |
|---|---|---|
| `StreamFlows(Empty) returns (stream FlowMeta)` | phone → Mac | Captured flow metadata, as traffic happens. The open stream is also the liveness signal. |
| `SetProxy(ProxyConfig) returns (Ack)` | Mac → phone | The address of the Mac's decryption proxy. The phone sends intercepted TLS there. |
| `Describe(Empty) returns (DeviceInfo)` | phone → Mac | The phone's description for the device list. |
| `InstallCa(CaCert) returns (Ack)` | Mac → phone | The Mac's root CA, so the phone can ask the user to install it. |

Reserved fields and the commented-out `GetTransactionDetail` RPC leave room for the deferred plan in [`docs/on-device-store-and-lazy-fetch.md`](../docs/on-device-store-and-lazy-fetch.md).

## Change the contract

1. Edit `companion.proto`.
2. Regenerate the Swift stubs with `./scripts/proto-gen.sh`. Do not edit `Sources/Core/Companion/Generated/` by hand.
3. Build the companion app (`./scripts/build-mobile.sh`). Gradle regenerates the Java stubs.
4. Update [`docs/companion-architecture.md`](../docs/companion-architecture.md) when the flow or the wire protocol changes.

`proto-gen.sh` needs these tools:

```bash
brew install protobuf swift-protobuf        # protoc + protoc-gen-swift
# grpc-swift 1.x plugin, to match the GRPC runtime in project.yml:
git clone --depth 1 --branch 1.27.5 https://github.com/grpc/grpc-swift.git /tmp/grpc-swift-1x
(cd /tmp/grpc-swift-1x && swift build -c release --product protoc-gen-grpc-swift)
```

If you build the plugin in another place, set `GRPC_SWIFT_PLUGIN` to its path. The script generates client stubs only (`Client=true,Server=false`).
